ISO Stock — suivi du matériel embarqué
======================================

INSTALLATION
Aucune. Copiez ce dossier où vous voulez (disque dur, clé USB)
et double-cliquez sur lancer.bat.

Java 17 ou plus récent doit être installé sur le poste.
Si ce n'est pas le cas : https://adoptium.net (gratuit).

UTILISATION
1. Stock      : saisissez d'abord ce que vous possédez (bouton Achat)
2. Véhicules  : cliquez sur un camion à gauche pour voir son contenu
3. Charger    : ajoutez du matériel dans le camion affiché
4. Ctrl+F     : rechercher un véhicule
5. Clic droit sur une ligne : modifier, déplacer ou retirer

SAUVEGARDE
Toutes les données sont dans le fichier parc.db, à côté de
l'application. Copiez-le régulièrement ailleurs : si vous le
perdez, tout est perdu.

MISE À JOUR
Remplacez uniquement ISO-Stock.jar par la nouvelle version.
Ne supprimez jamais parc.db : vos données sont dedans.

EN CAS DE PROBLÈME
Si rien ne s'ouvre, double-cliquez sur depannage.bat et envoyez
une capture d'écran de la fenêtre qui s'affiche.
